✅ What is @Repository in Spring?
The @Repository annotation is a Spring stereotype annotation that marks a class or interface as a data access layer — meaning it's meant to interact with the database.

🔹 It tells Spring two important things:
This class should be treated as a "Repository bean" — so Spring will detect it during component scanning and create an instance you can @Autowired anywhere.

It is part of the persistence layer — so Spring can apply special behavior to it (like exception translation).


✅ Why Is It Used on Interfaces Like RoleRepository?
When you extend JpaRepository<Role, Long>, you are telling Spring:

“Please create an implementation for this interface that can talk to the database and do CRUD operations.”

Then, when you add @Repository, Spring knows:
-This is a DAO (Data Access Object)
-It should be automatically managed by Spring
-It can be used anywhere in your app with @Autowired

Even though you're not writing SQL manually, Spring and Hibernate do the work for you.
